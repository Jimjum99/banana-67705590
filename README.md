# ตรวจจับความสุกของกล้วยด้วย YOLOv11 (Banana Ripeness Detection)

เว็บสำหรับตรวจจับกล้วยในรูปภาพและบอกระดับความสุก ใช้โมเดล **YOLOv11** ที่แปลงเป็นไฟล์ ONNX แล้วรันบนเบราว์เซอร์โดยตรงด้วย **ONNX Runtime Web** (ไม่ต้องมีเซิร์ฟเวอร์ประมวลผล)

## คลาสที่ตรวจจับได้

| คลาส | ความหมาย | สีกรอบ |
|------|----------|--------|
| `rotten` | เน่า | น้ำตาล |
| `ripe` | สุก | เหลือง |
| `freshunripe` | ดิบ | เขียว |

## ไฟล์ในโปรเจกต์

- `index.html` — หน้าเว็บหลัก
- `script.js` — โค้ดโหลดโมเดล ประมวลผลรูป และวาดกรอบผลลัพธ์
- `labels.json` — รายชื่อคลาส
- `best.onnx` — โมเดล YOLOv11 ที่เทรนแล้ว

## วิธีรันด้วย Live Server

1. เปิดโฟลเดอร์โปรเจกต์ใน **VS Code**
2. ติดตั้งส่วนขยาย **Live Server** (ของ Ritwick Dey) จากแท็บ Extensions
3. คลิกขวาที่ไฟล์ `index.html` แล้วเลือก **Open with Live Server**
4. เบราว์เซอร์จะเปิดหน้าเว็บขึ้นมา (เช่น `http://127.0.0.1:5500`)
5. กดเลือกรูปภาพ ระบบจะแสดงกรอบและระดับความสุกของกล้วยที่ตรวจเจอ

> หมายเหตุ: ต้องเปิดผ่าน Live Server (หรือเว็บเซิร์ฟเวอร์อื่น) เท่านั้น ถ้าดับเบิลคลิกเปิด `index.html` ตรงๆ เบราว์เซอร์จะโหลดไฟล์ `best.onnx` ไม่ได้
